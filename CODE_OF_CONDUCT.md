# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and never publish a victim's secret, personal data or working payload in
an issue, a pull request or a discussion.

To report unacceptable behavior, use the contact form at https://nukoe.com or a
[private report](https://github.com/nukoe-labs/wormsign/security/advisories/new). Reports are read by the maintainers
only and answered within 3 working days.
