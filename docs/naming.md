# Naming

## closedbox (since 2026-11-21)

The project was first called stillsuit, after the suit in Dune that lets nothing escape. The name was hard to
understand for anyone who has not read the book, so it became **closedbox**:

- **It says what the tool does**, in plain words: your assistant works in a closed box.
- **It is short and easy to type**: `npx github:nukoe-labs/closedbox claude`, with no hyphen and no number.
- **It is free where it matters**: the npm name is free, and only one small unrelated GitHub repository uses it.
  `closedbox.dev` and `closedbox.com` are already registered.

Checked on 2026-11-21 with `curl https://registry.npmjs.org/closedbox` (404 means free), a GitHub search of
repositories with that name, and RDAP for `.dev` and `.com`.

The old address, https://github.com/nukoe-labs/stillsuit, redirects to the new one.
